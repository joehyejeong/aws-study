# 배포 개념 교실

`index.html`을 브라우저로 열어 사용하세요. 기존 `docs/study/index.html`과 별개의 교재예요.

- React·Next·Python에 익숙한 프론트엔드 개발자를 위한 14개 단원
- 개념 설명 → 비유와 한계 → 단계별 흐름 → 복습 퀴즈 44개
- 환경변수 전달 경로·문제 해결 집중 단원과 가짜 값으로 동작하는 설정 실험실
- 용어 사전, 오답 복습, 단원별 메모, 읽음 표시
- 학습 내용과 기능은 오프라인에서 동작해요. 공식 문서 링크에는 인터넷이 필요해요.
- 진도와 메모는 현재 브라우저의 localStorage에 저장돼요. 브라우저·파일 위치·보안 설정에 따라 저장 공간이 달라지거나 제한될 수 있어요. 기기 간 동기화는 없어요.

이 교재는 배포 요구사항을 학습 자료로 만든 결과물이에요. AWS 리소스 생성, 실제 배포, 환경변수 변경, 운영 DB 연결을 수행하지 않아요. 기존 Compose는 서버 내부 PostgreSQL을 포함하며 목표인 별도 관리형 PostgreSQL과 다르다는 점을 본문에 표시했어요.

환경변수 설명은 `config/loadEnv.js`, `config/prismaClient.js`, `scripts/run-prisma.js`, Compose 파일을 대조했어요. 특히 앱 내부 dotenv override까지 다뤄요. 원본 코드나 배포 파일은 수정하지 않았어요.

## 수정과 재생성

내용: `web/content.py`, 화면 동작: `web/app.js`, 스타일: `web/style.css`, 틀: `web/template.html`.

저장소 루트에서 실행하세요. Python 표준 라이브러리만 사용해요.

```powershell
python docs/deployment-study/web/build.py
```

생성된 HTML 한 파일에 스타일·데이터·스크립트가 포함돼요. HTML만 이동해도 수업은 동작하지만 상대 경로의 저장소 문서 링크는 원래 폴더 배치가 필요해요. 실행 명령과 실험실은 교육용이며 운영 변경을 실행하는 버튼은 없어요.

기준일: 2026-11-24. 비용은 요청서의 월 기본 $42 가정을 설명하며 실제 AWS 서울 콘솔 견적 확인 결과가 아니에요. 공식 문서는 설치 버전에 맞춰 대조하세요.

## 확인한 범위

- Python 생성 및 JavaScript 문법 검사
- 브라우저에서 개념 14개, 흐름 선택, 퀴즈 44개 채점, 오답 재풀이와 검색 확인
- 메모·읽음 표시·정답 진행률의 새로고침 후 유지 확인
- 환경변수 실험실의 우선순위·재시작·재생성·앱 override 확인
- 390px 모바일 메뉴 및 가로 넘침 확인, file:// 직접 실행과 외부 리소스 요청 0건 확인

AWS 접속, 실제 서버 배포, 실제 DB·결제 검증은 수행하지 않았어요. 교재만 새로 만들었어요.
